# Roadmap

Completed work is recorded in [the changelog](CHANGELOG.md). The items below are active
areas where contributions would be useful.

## Learning Material

- Add advanced, self-contained programming examples.
- Document benchmarking and performance considerations, including the linear behavior
  of list membership operations such as `value in (list)` and `is_member()`.
- Add a focused guide to durable comments and documentation conventions in stored MOO
  verb code.
- Develop a concise history of LambdaMOO, its predecessors, and the environments that
  influenced it.

## Servers and Databases

- Add a current guide to choosing among LambdaMOO, Stunt, and ToastStunt.
- Document commonly used cores and databases and explain how server and database
  versions relate.
- Add or recover installation guides for current operating systems.
- Continue preserving server patches with source, version, and compatibility notes.

## Manual Maintenance

- Verify that generated function anchors match their function names.
- Review heading hierarchy and generated navigation in the updated Programmer's Manual.
- Continue replacing unavailable historical references with stable archived sources.
