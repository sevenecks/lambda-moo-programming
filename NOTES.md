# Maintenance Notes

- Markdown files under `tutorials/` are the readable editions maintained by this
  repository.
- Files under `tutorials/src/` preserve the HTML or text sources used to create those
  editions. Keep these snapshots intact when making readability or link repairs.
- Historical tutorials may contain obsolete commands, dependencies, hostnames, and
  version-specific advice. The README labels these documents as historical rather than
  silently presenting them as current guidance.
- The HTML edition of the updated LambdaMOO Programmer's Manual uses Bootstrap-oriented
  styling. Its stylesheet can be replaced with another compatible Bootstrap stylesheet.
- Built-in function documentation in the updated manual was formatted after the style
  of language-reference sites such as PHP.net.
